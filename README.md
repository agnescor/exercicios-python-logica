# Exercicios de Python - Logica e Algoritmos

Repositorio com exercicios de logica de programacao em Python, inspirados nas
aulas de algoritmos. Cada arquivo explora um conceito diferente, com
comentarios simples explicando o que o codigo esta fazendo.

## Exercicios

- **ex01.py** - variaveis, ordem de precedencia das operacoes e f-strings.
- **ex02.py** - calculo de um pedido de lanchonete (subtotal, desconto e total) com formatacao de valores.
- **ex03.py** - leitura de dados do usuario e montagem de um comprovante de aluguel de bicicletas, com funcao para formatar valores no padrao brasileiro (R$ 1.234,56).
- **ex04.py** - decisao com `if` / `elif` / `else` para liberar ou nao o acesso a uma academia, validando as entradas do usuario.
- **ex05.py** - quatro formas diferentes de tomar decisao em Python: `if` aninhado, `if`/`elif` encadeado, `match`/`case` e `match`/`case` com guarda (clausula `if`).

## Como executar

Qualquer exercicio pode ser rodado direto com o Python 3:

```bash
python3 ex01.py
```

Os exercicios ex03, ex04 e ex05 pedem dados pelo terminal (`input`), entao
basta responder as perguntas que aparecem.
